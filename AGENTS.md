# Repository Structure

This is a directory-per-topic learning path for building fullstack apps with React, NestJS, TypeScript, and MongoDB on Bun.

## Conventions

- Each file is 200-500 words. Self-contained.
- Code examples run with `bun run <file>` (backend) or in a Vite + React project scaffolded with `bun create vite` / NestJS CLI with `bunx nest new`.
- Files are numbered for reading order.
- Concept first, then working code. Mermaid diagrams where they clarify flows.
- No emojis. No filler.

## Commit Convention

- Conventional commits: `feat:`, `fix:`, `docs:`

## File Naming

- Two-digit prefix for ordering: `01-topic.md`
- Lowercase, hyphenated filenames.

## Structure

Each file follows this pattern:
1. What is it (one sentence)
2. Why it matters (one paragraph)
3. How it works (the core concept)
4. Code/example snippets
5. Common mistakes or trade-offs
